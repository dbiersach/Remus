# Day 9, Period 3: Color versions: test and measure

## Learning objectives

By the end of this period, each pair can:

- Test an enhancement before trusting it. **Measured by:** The color version passes `uv run pytest` and a one-game smoke test against Remus-WHITE with no illegal moves.
- Predict what the enhancement changes. **Measured by:** Each pair writes one sentence on the board: what should change, and how the class will see it in the match results.

## The files

This folder holds no engine code. Each pair works in its own color version folder in `period2/student/engines`, a complete copy of Remus-WHITE plus one enhancement. Remus-WHITE itself is in the `period1` folder.

## The period step by step

| Time | Activity |
| --- | --- |
| 1:00 to 1:40 | Pairs finish their color version code and pass its tests. |
| 1:40 to 2:10 | Each pair opens `smoke_test.py` in its version folder and presses Run in VS Code: one 2-minute game against Remus-WHITE, which checks only that the engine plays legal moves to the end. |
| 2:10 to 2:30 | Each pair writes one sentence on the board: what its enhancement should change, and how the class will see it. |

# Remus-WHITE: No enhancements

Remus-WHITE is the finished Day 9 Remus: alpha-beta with quiescence, move ordering, iterative deepening, and a clock, with none of the ten enhancements. This folder is an exact copy of the Day 9 `period1` instructor folder. Every enhanced engine beside it is this same engine with one enhancement added, and each one measures its strength against Remus-WHITE. No student pair edits this folder: it stays plain Remus so there is always something to compare against.

## Check it

Open `run_tests.py` in this folder and press Run.

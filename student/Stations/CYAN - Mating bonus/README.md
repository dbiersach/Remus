# CYAN station: Mating bonus

With a big material lead, drive the losing king to the edge and bring the winning king close.

This folder is the plain Day 9 Remus plus this one enhancement. The pair writes `mating_bonus()` in `evaluation.py`.

Check the work from inside this folder with `uv run pytest`. Then measure the gain from the Stations folder with `uv run station_match.py "CYAN - Mating bonus"`, which plays this Remus against the plain Day 9 Remus and adds every game to games/remus_games.pgn.

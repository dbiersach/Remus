# Day 2, Period 4: Remus2 against Stockfish 1500

3:00 to 4:30. Part of [Day 2: Remus2 searches and plays Stockfish](../Day_2_Syllabus.md).

## Goal

Remus2 plays Stockfish 1500, and the class sees what the search buys over Remus1.

## The big picture

The student pair types no code this period. Remus2 is finished in `engines/Remus2`, and the period puts it to work: the student pair's Remus2 plays its Remus1 from `engines/Remus1`, so the class sees what looking ahead buys over a random choice, then plays Stockfish 1500, and then each student plays it. Tomorrow morning the student pair copies every file of `engines/Remus2` into `engines/Remus3` and starts Remus3 from those copies, so a student pair that did not finish Remus2 finishes it first.
